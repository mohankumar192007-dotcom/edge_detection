# 🖼️ Edge Detection Using Basic Convolution

A simple, interactive image-processing web application built with **Streamlit** and **OpenCV** that applies horizontal, vertical, and combined convolution filters to identify and highlight edges in images.

---

## 🚀 Project Overview
Edge detection is a fundamental concept in Computer Vision and Image Processing. This project demonstrates how custom mathematical convolution kernels (such as **Sobel Filters**) can be applied to grayscale images to detect intensity changes and highlight object boundaries, shapes, and structural outlines.
